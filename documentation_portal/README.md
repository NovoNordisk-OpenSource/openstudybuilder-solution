# OpenStudyBuilder documentation portal

## Prerequisites

Node.js 20 is a prerequisite — see the [root README](../README.md#prerequisites).

## Project setup

```
npm ci
```

### Compiles and hot-reloads for development
```
npm run docs:dev
```

By default, the documentation should be browsable at http://localhost:8080.

### Compiles and minifies for production
```
npm run docs:build
```
